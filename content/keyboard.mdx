# Keyboard

Vicenda has ten menu shortcuts and a small set of keys that work inside a view.
This page lists all of them, because a shortcut nobody can find is a shortcut
that does not exist.

## Start here: the one that undoes something

**⌥⌘Z** puts back the message you just archived.

It is listed first because it is the only way back from the one action in
Vicenda that takes a message off the screen, and nothing on screen advertises
it. If you archive by accident, that is the key.

## The menus

| | |
| --- | --- |
| **⌘R** | Sync now |
| **⌥⌘Z** | Undo archive |
| **⌘0** | Go to Today |
| **⇧⌘K** | Filter this column |
| **⇧⌘D** | Demo Mode on and off |
| **⌘N** | New Vicenda window |
| **⇧⌘N** | Add an account |
| **⌥⌘T** | Templates |
| **⌘,** | Settings |
| **⌘[** | In Settings, back to all mailboxes |

Two of these are worth a sentence each.

**⇧⌘D** is [Demo Mode](/docs/privacy#demo-mode). It masks every identity at the
point the app reads its own data, so you can show the app, record it or take a
screenshot of it without showing your mail. It is a display switch: nothing is
rewritten and turning it off brings everything back.

**⇧⌘K** filters the column you are looking at rather than searching your whole
mailbox. What the column holds and why is on
[Channels and Threads](/docs/the-stream).

## Inside a view

These are not in a menu, because they only mean something where they work.

| | |
| --- | --- |
| **Esc** | In [Unread](/docs/triage#unread-in-one-place): mark the group you are in as read, and move to the next |
| **↑ ↓** | Move between rows |
| **← →** | Fold a group shut, and open it again |
| **Esc** | In an open message, thread or reader: close it |
| **Return** | Confirm the button a sheet is offering |

## Settings has a search field

Not a shortcut, but the same problem. **⌘,** then type: the Settings window
searches its own panes by name and by the words you would use instead of the
ones on screen, so looking for `sqlite`, `snooze` or `dark` lands on the right
row. It is there because a preference you cannot find is one you do not have.
