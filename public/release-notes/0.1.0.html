Vicenda 0.1.0

Release notes

Vicenda 0.1.0 — the first build you can download

The first public build of Vicenda, a Mac mail client shaped like a conversation: the machines that write to you get channels, the people get threads, and nothing ever leaves your Mac.

What is in it

  • Channels and threads. Machine senders become channels you visit; people become conversations that empty. Today opens on who is waiting for a reply, then on what is unread.
  • Cards for machine mail. Receipts, security advisories, renewals and deployment notices from recognised senders are drawn as cards with named fields — and only look authoritative when the receiving server vouched for the sender.
  • An optional local model. For senders no template knows, a model you download once and run on your Mac can build a card of its own, marked as such. Mail never leaves the machine, and the app is complete without it.
  • Gmail and IMAP. Gmail through Google's own API, reading and writing; any IMAP mailbox, read-only, with the credentials proved against the server before anything is saved.
  • Nothing phones home. No server, no telemetry, and every remote resource blocked before a message is rendered, so opening a message does not tell the sender.
  • One hue per mailbox, so seven accounts read at a glance — and a Demo Mode that masks the whole mailbox for a screenshot.

Requirements

macOS 15 or later. The optional local model needs an Apple silicon Mac.

Known limits

Sending is not built yet; archive and delete work on Gmail only. Google shows a warning on its consent screen while the app's verification is pending — Advanced, then Go to Vicenda.
